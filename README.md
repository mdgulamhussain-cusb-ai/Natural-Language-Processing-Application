# Natural Language Processing Application

An end-to-end NLP system for text classification and sentiment analysis using deep learning and transfer learning.

## Tech Stack
- TensorFlow / Keras
- NLTK
- Word Embeddings (GloVe)
- Pandas, NumPy, Scikit-learn

## Features
- Text preprocessing for unstructured data
- Transfer learning with pre-trained embeddings
- LSTM-based classification model
- Macro F1-score evaluation

## How to Run
```bash
pip install -r requirements.txt
python main.py
